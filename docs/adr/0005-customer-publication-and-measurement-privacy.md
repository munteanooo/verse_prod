# ADR 0005 — Public catalog projections and private measurement data

**Status:** Accepted

Read the current published version through a separate projection shared across pages, API and sitemap. Avoid reading latest draft content and avoid returning raw administrative rows. Keep the Phase 3 publication gate intact and seed published fixtures only in isolated automated tests.

Reuse exact canonical length arithmetic and version-defined fields for the customer form and admin preview. Calculate against the configured ranges with inclusive comparisons and explicit incomplete and ambiguous outcomes. Keep temporary values out of persistence, and persist them only through owner-scoped profile actions with snapshots and optimistic revision checks.
